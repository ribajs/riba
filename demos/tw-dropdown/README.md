# tw-dropdown Demo

Demonstrates the `tw-dropdown` component – a basic menu, four variants that differ only in their `placement` attribute, one that is operated with the keyboard and one with icon-decorated items – where the trigger is marked with `data-dropdown-trigger` and the panel with `data-dropdown-menu`. The first section adds a `tw-navbar` whose mobile menu is toggled through the `rv-on-click` binder, and the keyboard example annotates its shortcuts with `tw-kbd`.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/tw-dropdown
yarn install
yarn start
```
