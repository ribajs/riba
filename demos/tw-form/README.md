# tw-form Demo

Wraps plain HTML forms in the `tw-form` component, which collects the field values automatically via `auto-set-form-data` and, on submit, scrolls to and highlights the first invalid field when `scroll-to-invalid-element` and `animate-invalid-element` are set – a registration form, a contact form and a gallery of validation states. Native Tailwind utilities including `invalid:` variants style the required, email, `minlength` and `pattern` cases.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/tw-form
yarn install
yarn start
```
