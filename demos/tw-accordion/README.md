# tw-accordion Demo

Demonstrates the `tw-accordion` component in two variants – with `show-only-one="true"` so only a single panel is open at a time, and with `show-only-one="false"` so several `<template>` panels stay expanded together – plus the standalone `tw-collapse`, configured through its `title`, `content` and `collapsed` attributes and filled with arbitrary HTML.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/tw-accordion
yarn install
yarn start
```
