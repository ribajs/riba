# bs5-responsive-components Demo

Shows the responsive Bootstrap 5 binders `rv-bs5-attr-[breakpoint]-[attribute]` and `rv-bs5-co-[breakpoint]-[attribute]`, which set attribute values (e.g. the source or the size of an icon) depending on the currently active viewport breakpoint. In addition, a sidebar is demonstrated that automatically hides on small screens and is shown again on large ones.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/bs5-responsive-components
yarn install
yarn start
```
