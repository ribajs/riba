# bs5-accordion Demo

Demonstrates the Bootstrap 5 accordion component in two variants: one with static `<template>` child nodes and one with dynamic data binding via the `items` attribute as well as a separate `bs5-collapse` block.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/bs5-accordion
yarn install
yarn start
```
