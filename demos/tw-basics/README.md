# tw-basics Demo

Collects the small building blocks of the Tailwind module in one page: `tw-alert`, `tw-badge`, `tw-avatar`, `tw-card`, `tw-kbd`, `tw-skeleton`, `tw-progress`, `tw-rating`, `tw-breadcrumb`, `tw-button`, `tw-tooltip`, `tw-swap`, `tw-pagination`, `tw-colorpicker` and `tw-collapse`, each shown with its size, type and state attributes and, where the element needs no interaction markup, in its Tailwind-styled default. The standalone collapse sections are opened with the `rv-on-click` binder on the trigger button.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/tw-basics
yarn install
yarn start
```
