# tw-interactive Demo

Groups the interactive Tailwind components into one documentation-style page: a `tw-tagged-image` with `tag` children that reveal a caption per pin, a `tw-share` button that falls back to a dropdown where the Web Share API is missing, a `tw-slider` with drag scrolling and a `tw-collapse` FAQ driven by the `rv-on-click` binder. A `tw-scrollspy` reads the `h2` headings of the main area and renders a sticky table of contents beside it.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/tw-interactive
yarn install
yarn start
```
