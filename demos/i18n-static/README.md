# i18n-static Demo

Demonstrates the internationalization system (`@ribajs/i18n`) with statically embedded translations for German and English. A language switcher allows the texts, HTML content, input field values and placeholders of a newsletter form to be switched live between the languages via binding.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/i18n-static
yarn install
yarn start
```
