# tw-theme Demo

Demonstrates the light, dark and system theme switching of the Tailwind module through `tw-theme-button` in its `dropdown` and `icon` mode, and then puts the other components under the resulting `dark:` variant classes: `tw-sidebar` in overlap mode, `tw-notification-container` with its modal and toasts, `tw-collapse`, `tw-accordion`, `tw-dropdown` and `tw-alert`. The backdrop test sections exist to compare the overlay colours while the theme is toggled.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/tw-theme
yarn install
yarn start
```
