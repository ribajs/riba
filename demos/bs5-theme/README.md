# bs5-theme Demo

Demonstrates the light/dark theme system of Riba.js with Bootstrap 5, consisting of a fixed navbar with a hamburger menu, a collapsible sidebar and theme toggle buttons. The page automatically reacts to the operating system theme and lets the user switch between light and dark mode.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/bs5-theme
yarn install
yarn start
```
