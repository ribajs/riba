# tw-slideshow Demo

Demonstrates the sliding components of the Tailwind module over Tailwind `snap-x` scroll rows: a full-width `tw-slideshow` with controls, indicators and drag scrolling, a three-column `tw-carousel` that advances itself every three seconds, and a `tw-slider` for card rows. A `tw-slide-video` inside a slideshow starts and pauses its playback according to the active slide via `autoplay-on-active`.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/tw-slideshow
yarn install
yarn start
```
