# luxon Demo

Documents all Riba.js formatters of the `@ribajs/luxon` module for the Luxon date library. The formatter prefixes `lx-` (DateTime), `lx-duration-` (Duration) and `lx-interval-` (Interval) are illustrated with live outputs of the respective methods such as `lx-now`, `lx-local`, `lx-utc` and `lx-from-seconds`.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/luxon
yarn install
yarn start
```
