# bs5-slider Demo

Demonstrates the `bs5-slider` in three configurations: with default settings, with custom settings (2 columns, drag, infinite loop) and with video slides and autoplay – all of them with previous/next controls and indicators.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/bs5-slider
yarn install
yarn start
```
