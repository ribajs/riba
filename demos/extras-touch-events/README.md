# extras-touch-events Demo

Demonstrates the `rv-touch-events` binder from `@ribajs/extras`, which enriches a touch zone with touch and gesture events such as `tap`, `doubletap`, `taphold`, `swipe` (in all four directions) as well as `tapstart`/`tapend`. All triggered events appear with coordinates and a timestamp in a live console.

## Getting started

```bash
git clone --recurse-submodules https://github.com/ribajs/riba.git
cd riba/demos/extras-touch-events
yarn install
yarn start
```
